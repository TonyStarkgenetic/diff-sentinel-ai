# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.3.x   | Yes       |
| 1.2.x   | Yes       |
| < 1.2.0 | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within `diff-sentinel`, please do **not** open a public issue. Instead, report it via [GitHub Private Vulnerability Reporting](https://github.com/TonyStarkgenetic/diff-sentinel-ai/security/advisories/new) or contact the maintainers directly.

All reports are acknowledged within 48 hours, and a coordinated disclosure will be arranged once a patch is tested and released.
